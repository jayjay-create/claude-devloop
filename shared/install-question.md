Every point that carries the decision has a field of the widget, named here,
so that a reader of the skill sees whether a point has a place at all; each
field holds a short line, and nothing of the question stands in prose around
it.

- **In the question line: the subject and its scope.** Whether the run may
  from now on install tools and browsers for tests that land outside the
  project on this machine, the answer holding for this project. Nothing else
  stands there. The browsers stand in the subject because the guard holds their
  download against the record.
- **In the yes, label and line: what a yes means.** From then on the run
  installs such tools and browsers by itself, without asking again.
- **In the no, label and line: where a no leads, which differs by where the
  question is put.** Put at the setup of the project, the first time: the run
  installs nothing outside the project; where a tool or a browser is missing
  they get the command for it and decide themselves; and the exception, that
  some packages of their project download something themselves when they are
  installed, a browser for tests say, which the no does not stop. Put where
  the unattended mode is set up, the second time: the run installs nothing
  outside the project, the same exception, and work without them is then not
  possible, every piece of work running with them. The exception is said because
  a browser a package's installation downloads stays outside the guard, and a no
  that said nothing of it would imply something untrue.
- **In the header: a name for the subject**, of twelve characters at most,
  which is what that field holds, and as telling as it can be. It carries no
  point of the decision.

Two things stay out of the question, on purpose. It says nothing about
runtimes: that compilers and runtimes stay theirs under every answer is a
rule on the run, and not an assurance the guard holds. Said in the question, it
reaches the person as that assurance, so nothing of it is said. And the first no
does not say that work without them is then not possible: with them there a no
costs nothing that is not said, since they get the command each time, and the
consequence is said where it bites, at the second asking.

The examples of such a tool — a code generator, a migration command, a
checker — carry no decision and have no field. The standard is that nothing
in the question implies something untrue, not that everything true is said.
Give no recommendation. The call carries this question and no other.
